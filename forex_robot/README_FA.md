## 🚀 راهنمای نصب سریع (۵ دقیقه)

### مرحله ۱ — Python نصب کنید
از [python.org](https://python.org/downloads) نسخه **3.10 یا بالاتر** دانلود کنید.  
در حین نصب تیک **"Add to PATH"** را بزنید.

### مرحله ۲ — کتابخانه‌ها نصب کنید
```bash
# Windows:
setup.bat

# Mac / Linux:
bash setup.sh

# یا دستی:
pip install -r requirements.txt
```

### مرحله ۳ — MetaTrader 5 نصب کنید (برای معامله واقعی)
1. به سایت بروکرتان بروید و MT5 دانلود کنید
2. حساب Demo باز کنید
3. MT5 را باز کنید و وارد حسابتان شوید

### مرحله ۴ — config.py تنظیم کنید
فایل `config.py` را با Notepad باز کنید:

```python
MT5_LOGIN    = 12345678       # ← شماره حساب MT5 شما
MT5_PASSWORD = "رمز شما"     # ← پسورد حساب
MT5_SERVER   = "ICMarkets-Demo"  # ← نام سرور بروکر

MODE = "DEMO"   # ← "DEMO" برای تمرین | "LIVE" برای واقعی
RISK_PCT_PER_TRADE = 1.0  # ← 1% ریسک هر معامله (توصیه می‌شود)
```

## ⚙️ منطق استراتژی

ربات **فقط** وقتی همه شرایط برقرار باشند وارد می‌شود:

### سیگنال خرید (BUY)
```
✓ قیمت نزدیک سطح Fibonacci (38.2% / 50% / 61.8%) بعد از موج صعودی
✓ قیمت نزدیک Ichimoku Kijun Sen (حمایت طبیعی)
✓ کندل صعودی (تأیید برگشت)
✓ RSI < 55 (اشباع خرید نیست)
✓ ADX > 20 (کمی روند وجود دارد)
```

### سیگنال فروش (SELL)
```
✓ قیمت نزدیک سطح Fibonacci (38.2% / 50% / 61.8%) بعد از موج نزولی
✓ قیمت نزدیک Ichimoku Kijun Sen (مقاومت طبیعی)
✓ کندل نزولی
✓ RSI > 45
✓ ADX > 20
```

### مدیریت معامله
```
Stop Loss:  1.2 × ATR14 (خودکار و هوشمند)
TP1:        1× SL دور  → 33% پوزیشن بسته می‌شود
TP2:        2× SL دور  → 33% پوزیشن بسته می‌شود  
TP3:        3× SL دور  → 34% باقیمانده بسته می‌شود
```

## ❓ سؤالات رایج

**Q: آیا باید MT5 همیشه باز باشد؟**  
A: بله. MT5 باید روی کامپیوتر یا VPS روشن باشد.

**Q: VPS چیست؟**  
A: یک سرور مجازی که ۲۴/۷ روشن است. برای معامله زنده توصیه می‌شود.  
هزینه: حدود $5-10/ماه (Vultr, DigitalOcean, Forex VPS).

**Q: چطور از Demo به Live سوئیچ کنم؟**  
A: در `config.py` مقدار `MODE = "LIVE"` بگذارید.  
⚠️ قبلاً حتماً چند هفته Demo تست کنید!

**Q: چرا معاملات کم است؟**  
A: این استراتژی کیفیت را به کمیت ترجیح می‌دهد. در Daily تایم‌فریم، ماهی ۲-۴ معامله طبیعی است.
